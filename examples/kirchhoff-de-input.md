# Kirchhoff's laws through the toolbox — German input

Demonstration of the `reframe-through-structure` skill over the `lat` catalogue.
Lenses are grounded in real `search_patterns` hits; the input language (German)
is excluded via `exclude_names` so contrasting lenses surface.

**Input language:** German → `exclude_names: ["German", "English"]` (baseline
pair, both carry the causal-chain bias).

**Source.** KCL (node rule): ΣI at a node = 0 — "what flows in must flow out".
KVL (loop rule): ΣU in a loop = 0 — "the sum of voltage drops equals the sum of
source voltages".

## 1 · Diagnose the bias (German phrasing)

- "in … **must** flow out" imposes a *temporal sequence* (first in, then out) and
  a *modal necessity* on what is actually a **balance** → axis **Causality**.
- "**source** voltages" (active) vs. "voltage **drops**" (suffering), "equals" as
  one-way → actor-patient rank → axis **Agency & rank**.
- Physically both are a *simultaneous equilibrium* (Σ = 0) → the target axes are
  **Coexistence** and **Perspective & reciprocity**.

## 2 · Contrast selection

Input is German → exclude both baselines (`["German", "English"]`). English
(parataxis = coexistence) would be the obvious lens but is excluded as a
baseline; so **Classical Chinese** and **Enumeration** carry the coexistence
load instead — a stranger, more revealing result. Forms are language-neutral.

Grounded lenses (with `focus`):
- **Classical Chinese** — *"Pure relational constellation in the now"* (Coexistence)
- **Japanese** — *"Topic instead of agent"* + technique **Perspective swap** (Perspective & reciprocity)
- **Enumeration** — *"Coexistence instead of causality; no direction-asserting verbs"* (form)
- **Word ban**, **Chiasmus** — Causality-breaking forms
- **Ancient Greek** — *"Geometric shape of an action"* (aorist / middle voice)

## 3 · Reformulations

### Node rule (KCL)

- **Classical Chinese / parallel constellation:** "Node: inflow, outflow —
  level." No "must", no "then"; two quantities in parallel, equality as a static
  relation. → *reveals:* it is a **balance, not an event** — nothing happens
  "first" and "after".
- **Perspective swap / Japanese *wa*:** "As for the node — the currents sum to
  nothing." No agent drives the current out. → *reveals:* **no causer**; ΣI = 0
  is a *state of the node*, not an action performed on it.
- **Enumeration (no directional verbs):** "Branch 1: +i₁. Branch 2: −i₂.
  Branch 3: +i₃. Together: zero." → *reveals:* **coexistence** — all branch
  currents are simultaneously present; the "0" is their co-presence, not a
  consequence.

*Revelation (KCL):* "must … out" smuggles in time and compulsion. Because the
node stores no charge, ΣI = 0 holds **at every instant simultaneously** —
conservation as coexistence, not "in, then out".

### Loop rule (KVL)

- **Word ban** (drop "source causes", "as a consequence", one-way "equals"):
  "Around the loop: all voltages, together zero." → *reveals:* source and drop
  are **co-equal terms of one sum**, not cause and effect.
- **Chiasmus (A-B : B-A):** "The sources carry the drops, the drops mirror the
  sources." → *reveals:* the **reciprocity** — neither is prior; the loop is one
  constraint seen from two sides. The source→drop rank dissolves.
- **Ancient Greek / middle voice + aorist:** "in circulation: voltage,
  cancelling" — as a timeless point, the subject as the *space* of the action
  (neither actor nor patient). → *reveals:* KVL is a **topological constraint**
  on the closed path (the potential is single-valued), not a temporal
  "adding-up".

*Revelation (KVL):* "source voltages" as causes and "drops" as effects is a
grammatical rank the physics lacks — around any closed path the potential
returns to itself; a **reciprocal**, fully symmetric constraint.

## 4 · Overarching revelation

Both laws are **the same thing** — a closed "Σ = 0", a simultaneous equilibrium
(KCL: charge conservation as co-presence; KVL: single-valued potential as a
reciprocal loop constraint). German/English grammar splits this one idea into
two *differently narrated* rules — one a flow sequence, the other a
cause-effect assignment. The "must", the "then", the source-before-drop rank:
**linguistic artifacts, not features of the matter.**

## 5 · Framing

No version is more correct than the textbook; the equations are unchanged. But
the detour shows the typical learning difficulty ("what causes what here?") sits
in the causal *form of telling*, not in Kirchhoff. The laws are **balances, not
chains.**
